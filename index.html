Leaflet

leaflet-quito.html

Biblioteca ligera y clasica para mapas 2D. Ideal para proyectos que necesitan simplicidad, rapida configuracion y un ecosistema extenso de plugins.

MapLibre GL

maplibre-quito.html

Motor de mapas basado en WebGL con soporte para estilos vectoriales, pitch 3D, rotacion y renderizado acelerado por GPU. Fork libre de Mapbox GL JS.

Ver mapa MapLibre
MapLibre GL 4.7.1 CARTO GL Styles Vector Tiles WebGL FlyTo Animations
  • Mapa vectorial con WebGL
  • Vista 3D (pitch y bearing)
  • Estilos vectoriales (GL JSON)
  • Markers HTML/SVG
  • Animaciones flyTo
  • Medicion de distancias
  • Geolocalizacion
  • Tema claro/oscuro

OpenLayers

openlayers-quito.html

Framework GIS completo y robusto. Soporte nativo para proyecciones, formatos OGC (WMS, WFS), y operaciones geoespaciales avanzadas.

Ver mapa OpenLayers

  • Overlays personalizados
  • Feature styling con SVG

  • Medicion con Haversine
  • Geolocalizacion
  • Tema claro/oscuro
  • ScaleLine metrica

GeoExt

geoext-quito.html

Framework GIS que combina la potencia de OpenLayers con la interfaz de usuario de ExtJS. Ofrece componentes UI avanzados como arboles de capas, grillas de features y popups integrados.

Stack tecnologico

Tecnologias y funciones utilizadas

Detalle de las tecnologias, APIs y patrones de diseno empleados en cada uno de los cuatro mapas interactivos.

Leaflet - Funciones clave

  • L.map() - Inicializacion del mapa con centro, zoom y controles
  • L.tileLayer() - Carga de tiles raster desde CARTO y OSM
  • L.control.layers() - Selector de capas base integrado
  • L.control.scale() - Barra de escala metrica
  • L.Control.MiniMap - Mini-mapa de posicion (plugin)
  • L.divIcon() - Marcadores personalizados con HTML/CSS
  • L.layerGroup() - Grupo de capas para gestion de markers
  • L.polyline() - Linea discontinua para medicion
  • L.circleMarker() - Puntos de medicion y geolocalizacion
  • marker.bindPopup() - Popups informativos por marker
  • latlng.distanceTo() - Calculo de distancia geodesica
  • map.setView() - Navegacion animada a coordenadas

MapLibre GL - Funciones clave

  • new maplibregl.Map() - Mapa WebGL con estilo vectorial
  • style.json - Estilos CARTO Dark Matter y Positron
  • NavigationControl - Zoom, brujula y pitch visual
  • ScaleControl - Escala metrica integrada
  • maplibregl.Marker() - Marcadores HTML con SVG personalizado
  • maplibregl.Popup() - Popups estilizados
  • map.setStyle() - Cambio dinamico de estilo vectorial
  • map.flyTo() - Animaciones de vuelo suaves
  • map.easeTo() - Transicion suave a pitch 3D
  • map.once('styledata') - Evento de recarga de estilo
  • GeoJSON Source - Fuente para medicion (FeatureCollection)
  • lngLat.distanceTo() - Distancia entre puntos

OpenLayers - Funciones clave

  • new ol.Map() - Mapa con vista, capas y controles
  • ol.View - Vista con proyeccion EPSG:3857
  • ol.proj.fromLonLat() - Conversion WGS84 a Web Mercator
  • ol.proj.toLonLat() - Conversion inversa a coordenadas geograficas
  • ol.layer.Tile - Capas raster (OSM, CARTO XYZ)
  • ol.layer.Vector - Capa vectorial para features y medicion
  • ol.source.Vector - Fuente de datos vectorial
  • ol.Feature - Entidades geograficas con propiedades
  • ol.geom.Point / LineString - Geometrias vectoriales
  • ol.style.Icon - Iconos SVG inline para markers
  • ol.Overlay - Popup overlay posicionado
  • ol.control.ScaleLine - Escala metrica
  • Formula Haversine - Calculo manual de distancias
  • view.animate() - Animaciones de vista

GeoExt - Funciones clave

  • Ext.application() - Inicializacion de la aplicacion ExtJS
  • GeoExt.component.Map - Componente que envuelve un ol.Map
  • GeoExt.component.Popup - Popup integrado con el mapa
  • Ext.Loader.setConfig() - Carga dinamica de clases GeoExt
  • ol.Map - Mapa base con proyeccion EPSG:3857
  • ol.layer.Tile - Capas raster (OSM, CARTO XYZ)
  • ol.layer.Vector - Capa vectorial para features y medicion
  • ol.Overlay - Overlay para popup personalizado
  • ol.style.Icon - Iconos SVG inline para markers
  • pointerrest event - Evento GeoExt al descansar puntero
  • Formula Haversine - Calculo manual de distancias
  • view.animate() - Animaciones de vista

Tecnologias comunes

  • HTML5 + CSS3 - Estructura y estilos con CSS Custom Properties
  • backdrop-filter - Efecto glassmorphism en paneles
  • CSS Grid - Layout principal (panel lateral + mapa)
  • CSS Variables - Sistema de temas (dark/light)
  • Vanilla JavaScript - Sin frameworks, JS puro (ES5+)
  • Geolocation API - navigator.geolocation para ubicacion
  • Fullscreen API - document.requestFullscreen()
  • Font Awesome 6.5 - Iconografia vectorial
  • Google Fonts - Inter + Playfair Display
  • CARTO Basemaps - Tiles dark_all / light_all
  • OpenStreetMap - Tiles raster libres
  • Responsive Design - Adaptacion mobile con media queries
